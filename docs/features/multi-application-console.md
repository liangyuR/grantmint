# 中文多应用管理页面

管理后台为普通 React Web 页面，通过同源 Rust API 使用服务端会话。无需 Tauri、桌面安装包或浏览器中保存管理 token；默认中文。

## 页面

- **应用管理**：创建/编辑应用，选择部署人员预置的签名公钥，查看 UUID 和公钥；UUID/slug 不可修改，已有应用只能归档。
- **授权管理**：按当前应用列出客户、状态、合同修订、设备交付状态和北京时间停用时刻。创建直接填写客户、未来停用日及可选权益。
- **授权详情**：设备公钥/指纹摘要、期限、提前七天提醒时刻、权益快照、续期记录；支持续期和撤销，不能解绑设备。
- **操作审计**：按当前应用查看创建、激活、续期、确认、撤销和密钥操作，避免将秘密、私钥或完整证书写入审计。

切换应用清空未提交表单，并隔离其他应用的保存链接详情。慢速登录会话检查结束前不允许再次登录；写操作带服务器下发的 CSRF token。激活秘密只在创建结果中展示，关闭后清除，不写 localStorage。

## 业务提示

停用日期表示所选日期北京时间 00:00，不是当天结束；同时显示提前七天的提醒时刻。后台显示的提醒日期不是服务端推送承诺，离线客户软件运行时自行计算并展示。

续期成功只表示后台合同和证书已更新。客户端验证并原子保存后完成独立确认，后台才显示“设备已确认”；尚未领取继续按旧证书到期。撤销不能即时停止未联网设备的旧证书。归档应用禁止新建/续期，保留原合同激活与同步。

没有策略页、v1 演示、模式选择、多席位、心跳、支付或私钥上传入口。
