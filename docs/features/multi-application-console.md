# 多应用管理控制台

本阶段复用 Grantmint 的 Product、Policy 和 License 模型，提供共享应用上下文。管理员拥有所有产品的管理权限；应用选择器用于操作定位，不是产品级 RBAC 或多租户权限隔离。

## 使用流程

1. 登录管理页面，在 Products 创建产品，填写不可变 slug、名称和说明。一个软件对应一个产品；客户和授权属于该产品。
2. 选择当前产品后进入产品详情，核对不可变产品 ID、slug 和签名公钥列表。私钥由部署人员导入，页面不接收或显示私钥。
3. 进入 Policies 管理该产品的策略和权益；进入 Licenses 查看该产品的授权。导航间保持同一产品选择。
4. 切换产品会清空旧产品的表单、筛选、策略选中状态和授权详情，避免用旧产品数据对新产品操作。授权详情链接属于其他产品时不显示该详情；先切换到正确产品。
5. 删除已有关联授权的产品会被拒绝；删除无授权产品会连带删除其策略、签名密钥记录及 API key，执行前核对产品名称。

授权签发表单固定使用当前产品及其策略。显式填写 Stop date 时，日期按北京时间当天 00:00 转换为 UTC，例如 2026-12-01 提交为 2026-11-30T16:00:00Z；不填则沿用策略期限。当前 v1 token 的宽限期规则仍然存在，表单不会把策略自动改为零宽限，也没有实现七天提醒。

签名密钥状态 active 表示该密钥可用，不等于它一定是该产品当前签发使用的密钥；已有服务端接口未返回 activeSigningKeyId，页面不推测当前签发密钥。

## 范围

本阶段不实现 v2 设备证书、长期离线策略、续期重签或到期提醒。现有策略仍使用 Grantmint v1 的心跳与宽限期规则，不能把 maxSeats=1 当成完整的长期离线单机授权。
